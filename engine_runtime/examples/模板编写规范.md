# 模板编写规范

> 配置生成器 · 模板作者指南
> 本文档告诉你：如何编写一个能被工具正确解析的配置模板。
> 工具不识别设备类型（交换机/路由器/WLC 都一样），它只认下面的格式约定。

---

## 1. 模板文件基本要求

- **文件格式**：`.xlsx`（推荐，保留格式和图片）或 `.txt`（纯文本，无样式）
- **列结构**：A 列 = 命令；B~E 列 = 注释（可合并单元格）
- **编辑工具**：用 Excel / WPS 正常编辑保存。
  **不要用脚本工具（openpyxl 等）另存**——会丢失嵌入图片，还可能误报样式变化
- 注释列会同时用于两个地方：
  1. 生成 Excel 时进 B 列
  2. 填写参数时作为该行的**输入提示**（可用来放参考值、保险库链接等）

## 2. 功能段落：`! --- 段名 ---`

模板按功能分成若干段，每段一个独立模板，生成时可单选/多选组合。

```
! --- Basic Configuration ---
hostname {{hostname}}
enable secret {{enable password}}
!
! --- VLAN Configuration ---
vlan {{vlan id}}
 name {{vlan name}}
```

**规则：**

- 分隔行格式必须是 `! --- 段名 ---`（`!` 开头，`---` 包裹段名）
- **段名必须唯一**，且尽量语义化（生成界面上显示的就是段名）
- 段与段之间建议用 `!` 空行隔开，便于阅读

## 3. 占位符：`{{变量名}}`

需要填写的值用双大括号包裹，变量名任意，**会原样显示为提问语**：

```
hostname {{hostname}}
ip address {{interface ip}} {{subnet mask}}
snmp-server community {{snmp community}} RO
```

**规则：**

- 变量名写人能看懂的话，如 `{{VLAN id}}`，不要写 `{{v1}}`
- 同一变量名出现多次，只问一次，处处替换（如 `{{hostname}}`）
- **任何值都可以留空**：留空时命令行保留、值为空，事后在 Excel 里补
- 密码类也是明文占位符，生成后注意文件保管

## 4. 可重复块：`@repeat`（多 VLAN、多接口）

一段需要"逐条添加、数量不定"的配置，用 `@repeat` 包裹：

```
! @repeat 添加 VLAN（id + name）
vlan {{vlan id}}
 name {{vlan name}}
! @end
```

**生成时行为**：填完一条问"再添加一条吗"，可一直加；GUI 中每条带删除按钮。

**规则：**

- 块内可以有多个占位符，也可以有固定命令行
- 块外的固定行原样输出，不受影响
- 一个段落里可以有多个 `@repeat` 块
- **成员相关块**（变量名含 member，如 `{{member 号}}`）：条数超过
  stack member 数时会警告提示，但不阻止继续

## 5. 选择块：`@choice`（几选一）

一段配置有几个互斥方案（如 AAA 分区域四选一）：

```
! @choice 选择 AAA 区域方案
! @option NA
tacacs-server host {{tacacs server 1}}
! @option EU
tacacs-server host {{tacacs server 2}}
! @end
```

**生成时行为**：显示选项列表，选一个，只输出该选项的正文。

**规则：**

- `! @choice 提示语` 开头，每个选项一行 `! @option 选项名`
- 选项正文从 `@option` 下一行开始，到下一个 `@option` 或 `@end` 为止
- 必须以 `! @end` 收尾，**忘了 `@end` 会吞掉后面的正常配置行**
  （不过导入后检查报告会报"解析丢失 N 行"，能被发现）

## 6. 堆叠图片段：`if {{stack member}}==N` + 嵌入图片

堆叠连线图按成员数自动选图嵌入输出 Excel：

```
! --- Stack Picture Selection ---
if {{stack member}}==2
[此处嵌入 2 台堆叠连线图]
if {{stack member}}==3
[此处嵌入 3 台堆叠连线图]
! @end
```

**规则：**

- 判断条件写成独立一行：`if {{stack member}}==N`（N 为成员数）
- 图片直接嵌入在条件行下方的单元格区域（Excel 里正常插图即可）
- 导入时自动提取图片并与条件绑定；**缺了某个成员数的图，检查报告会提示**
- 生成时按实际 stack member 数自动嵌入对应图片，无需手工选

## 7. 堆叠配置段

含 `{{stack member}}` 占位符或堆叠专用内容的段会被自动识别为堆叠相关，
**不需要声明设备类型**——OT switch、Server switch 模板同样适用。

堆叠参数化（priority / renumber）有内置逻辑：

- `switch X priority Y`：按成员数自动生成，默认 Y = 16-X，可逐台修改
- `switch A renumber B` + reload：可选逐条添加

参考现有 `switch/access` 库里的 stack_configuration 模板写法即可。

## 8. 分类与命名

导入时填写**两级分类**，格式 `大类/小类`，例如：

| 分类 | 适用 |
|---|---|
| `switch/access` | 接入交换机 |
| `switch/ot` | OT 交换机 |
| `switch/core` | 核心交换机 |
| `router/edge` | 边界路由器 |
| `wlc/` 或 `wlc/9800` | 无线控制器 |

- 分类名**自己起、随意起**，已有的分类导入窗口会列出来供选择
- 同一分类下可以有任意多个功能段模板
- 每个模板自动带版本号（v1.0、v1.1…），重复导入同段名会自动对比

## 9. 导入与版本更新流程

1. GUI 主窗口点 **导入模板** → 选文件 → 填分类 → 点 **解析文件**
2. 预览列表会显示每段状态：`[新增] / [内容有变化] / [样式有变化] / [无变化]`
3. 勾选要导入的段 → 点导入：
   - **新增**：直接入库 v1.0
   - **内容有变化**：选"新版本"（旧版保留，推荐）或"覆盖"
   - **样式有变化**：静默自动更新样式，不产生新版本，无需操作
   - **无变化**：自动跳过
4. 导入后自动输出**检查报告**，列出需人工确认项：
   - 解析丢失行（必查！说明 @end 缺失或格式问题）
   - 变量类型猜测异常
   - 堆叠图片缺失的成员数
   - 纯固定内容段（无占位符，确认是否有意为之）

## 10. 格式与样式

- **输出严格沿用模板格式**：字体（名称/字号/加粗/斜体/颜色）、单元格底色、
  边框、对齐、行高、列宽，全部逐行复制
- 想改输出字体/样式：**改源 xlsx → 重新导入**即可，不用改任何代码
- 段落分隔行（`! --- ---`）加粗、`!` 注释行灰色斜体等样式，
  直接在模板里把那一行做成想要的样子，导入后生成就是这个效果

## 11. 常见错误自查表

| 现象 | 原因 | 处理 |
|---|---|---|
| 检查报告报"解析丢失 N 行" | `@choice`/`@repeat` 块缺 `@end` | 补上 `@end` 重新导入 |
| 选择块只能选第一个选项 | `@option` 行格式不对（须 `! ` 开头） | 检查 `@option` 拼写和前缀 |
| 堆叠图没嵌进去 | 缺对应成员数的 `if==N` 图片 | 补图或在库里 images/ 手动放 |
| 段被拆错/合并错 | 段名不唯一或分隔行格式错 | 检查 `! --- 段名 ---` 格式 |
| 导入后样式没更新 | 用脚本工具另存过 xlsx | 用 Excel/WPS 重新保存再导入 |
| 变量没被提问 | 占位符写成了单大括号或全角括号 | 改为半角 `{{ }}` |

## 12. 手动修改库文件（高级）

导入后的模板在 `library/<分类>/<模板名>/<版本>/` 下：

```
template.txt    # 模板正文（可直接文本编辑）
schema.json     # 解析结果（变量/块结构）
styles.json     # 逐行样式（勿手改，重新导入会覆盖）
images/         # 堆叠图片（可直接替换 png）
```

小改动（改提示语、改个命令）直接改 `template.txt` 后重新导入该文件最快。
